# Comprendre le concept

Un jeu d'évasion web (ou escape game virtuel) est une expérience interactive en ligne où les joueurs doivent résoudre des énigmes, fouiller un décor numérique et décoder des indices pour accomplir une mission ou « s'échapper » dans un temps imparti


Les piliers du concept

• La trame narrative : Un scénario immersif qui donne un but (ex. : s'échapper d'un laboratoire abandonné, désamorcer une cyber-attaque, résoudre une enquête policière).

• L’interface visuelle : Une page web, une image interactive ou une présentation enrichie contenant des zones cliquables, des objets à ramasser et un inventaire.

• La progression par énigmes : Un enchaînement de codes, de cadenas numériques, de jeux de logique, de mathématiques ou de rébus pour déverrouiller de nouvelles étapes.

!!! warning "Pas de choix de réponse"

    Dans ce type de jeu, il est important de ne pas laisser à l'utilisateur un choix de réponse. Celui-ci ne doit pas résoudre une énigme par élimination. Il doit l'avoir résolue.

#### Variantes

* Énigme vague, mais la réponse est carrément écrite dans le code du site, dans le texte alternatif d'une image ou dans le titre de l'onglet !

* **Indices cachés**
  * Exemple 1 : texte de la même couleur que la couleur de fond. 
  * Exemple 2 : hover sur une image pour la faire disparaître en CSS et en arrière se trouve le mot recherché.
* **Énigme audio**
* **Énigme dans une image**
  * Exemple : un montage de photos affiche plusieurs images avec un même objet. Le nom de l'objet est la réponse.
